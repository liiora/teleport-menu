# TeleportMenu

A minimap menu for **WoW 1.12** that lists every teleport you can use right now and casts it with one click.

## Features

- Minimap button: left-click opens the menu, drag moves the button
- Only shows what is currently usable (learned spells, items in your bags, correct class)
- Shows cooldowns and the usual spell/item tooltips
- Covers:
  - Mage teleports and portals (Alliance and Horde)
  - Druid: Teleport: Moonglade
  - Shaman: Astral Recall
  - Hearthstone
  - Engineering: Ultrasafe Transporter: Gadgetzan, Dimensional Ripper - Everlook
  - Runes items
- Add your own spells/items in-game

## Slash commands

| Command | Description |
|---|---|
| `/tpm` | Addon help and info |
| `/tpm addspell <name>` | Add a custom spell (partial names work) |
| `/tpm additem <name>` | Add a custom item (partial names work) |
| `/tpm del <name>` | Remove a custom entry |
| `/tpm list` | List custom entries |
| `/tpm reset` | Reset the minimap button position |
